remimem 0.2.0: a local dashboard.

remimem is a local-first MCP server and CLI that gives coding agents only the code they need, within a token budget, and remembers your project. This release lets you see what it knows.

## What is new

- **A dashboard in your browser.** Run `remimem dashboard` in an indexed project, or let your agent's `remimem serve` run it. Five views:
  - **Health:** index size, freshness, re-index buttons, tokens saved per day and per tool, languages, and the setup checks.
  - **Graph:** the project one folder at a time, linked by calls and type uses. Click a file for its symbols with their callers and callees, marked `exact`, `import`, or `name-match`.
  - **Search:** the agent's own search and packing, with each result's score and reasons and the exact answer the agent would receive.
  - **Memory:** add, edit, filter, and forget decisions, conventions, gotchas, and todos, with stale ones flagged.
  - **Settings:** edit `.remimem/config.json`, checked before saving and used by the running server at once.
- **Locked down by default.** The dashboard listens on 127.0.0.1 only, needs the random token in its address, rejects requests for other host names (DNS rebinding), and accepts changes only from its own page. `dashboard.enabled: false` keeps `remimem serve` from opening a port.
- **A friendlier CLI.** A welcome screen, help grouped by task with examples, and a drawing of the model download.

## Upgrading

Nothing to migrate. The index format is unchanged. Note that `remimem serve` now opens a local port; set `"dashboard": { "enabled": false }` in `.remimem/config.json` to turn that off.

## Getting started

```sh
npx -y remimem init
npx -y remimem dashboard
```
