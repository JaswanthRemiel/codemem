Configuration is optional. It lives in `.remimem/config.json` in the project, which `remimem init` creates empty. Every field has a default, and the file is validated on load: unknown keys are rejected, so a typo does not silently fall back to a default.

```json title=".remimem/config.json"
{
  "include": ["src/**"],
  "exclude": ["**/*.test.ts"],
  "embedding": { "provider": "local" },
  "retrieval": { "defaultBudgetTokens": 6000 }
}
```

Changes take effect on the next command. A running MCP server reads the config once at start, so restart it from your client.

## Files

<TypeTable
  type={{
    include: { description: 'Globs a file must match to be indexed. Empty means every file.', type: 'string[]', default: '[]' },
    exclude: { description: 'Globs that remove files from the index, on top of the built-in excludes.', type: 'string[]', default: '[]' },
    maxFileSizeKb: { description: 'Files larger than this are skipped.', type: 'number', default: '512' },
  }}
/>

Globs are matched against paths relative to the project root, with forward slashes, using Node.js's `path.matchesGlob`. The built-in rules (vendored folders, lockfiles, generated files, binaries, secrets) always apply; see [Indexing](/docs/concepts/indexing).

## embedding

<TypeTable
  type={{
    provider: { description: 'local runs on this machine. openai and voyage send code to that service. none disables vectors.', type: '"local" | "openai" | "voyage" | "none"', default: '"local"' },
    model: { description: 'Model name. Empty means the provider default: Xenova/all-MiniLM-L6-v2, text-embedding-3-small, or voyage-code-3.', type: 'string', default: '""' },
    batchSize: { description: 'Texts per embedding call.', type: 'number', default: '8' },
    maxTokens: { description: 'Local models only: inputs are cut to this many model tokens.', type: 'number', default: '256' },

API keys come from `OPENAI_API_KEY` and `VOYAGE_API_KEY`, never from this file. After changing `provider` or `model`, run `remimem index --full`. See [Embedding providers](/docs/guides/embedding-providers).

## Where the defaults come from

The search, graph, and memory defaults were chosen on the training split of the [benchmark](/docs/benchmark) and checked on held-out tasks. `textFileWeight` and `memoryMinSimilarity` were changed by that tuning; the rest held up as first chosen. Run `npx . bench --tune` from a checkout to try your own values.

## Errors

An invalid file stops every command with a message that names the field:

```text
error: Invalid .remimem/config.json:
  Unrecognized key: "rrfk"
  at retrieval
```

(The real output also prefixes the first line of each problem with a cross mark and the second with an arrow.) A file that is not valid JSON says so, with the position of the error:

```text
error: .remimem/config.json is not valid JSON: SyntaxError: Expected property name or '}' in JSON at position 2 (line 1 column 3)
```

Fix the file, or delete it to go back to the defaults.
