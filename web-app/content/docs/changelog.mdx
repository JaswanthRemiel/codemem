remimem follows [Semantic Versioning](https://semver.org). While the version is below 1.0.0, a minor version may contain breaking changes. The changelog in the repository is the source; this page mirrors it.

## 0.2.0

- **Dashboard:** a local page with the code graph (folders and files, then the symbols of a file with their callers and callees), a search playground that shows scores, reasons, and the packed answer, a memory manager, savings per day and per tool, the setup checks, and a settings editor. `remimem serve` runs it alongside the tools; `remimem dashboard` opens it, or starts one when no agent is running. It listens on 127.0.0.1 only and every request needs the token in its address.
- **Configuration:** `dashboard.enabled` and `dashboard.port`.
- **index_status** reports the dashboard's address.
- **CLI:** a welcome screen for a bare `remimem`, help grouped by task with examples, and a drawing of the embedding model download.

## 0.1.0 (2026-11-15)

First release.

- **Indexing:** a scanner that respects `.gitignore` and skips vendored, generated, binary, oversized, and secret-looking files; tree-sitter parsing for TypeScript, TSX, JavaScript, Python, and Go; one chunk per function, method, type, and class header; line windows for every other text file.
- **Storage:** one SQLite file per project, with an identifier-aware keyword index, vectors in `sqlite-vec`, and numbered migrations.
- **Embeddings:** a local model by default (`Xenova/all-MiniLM-L6-v2`), optional OpenAI and Voyage providers, and a cache so unchanged text is never embedded twice.
- **Search:** keyword and vector rankings fused by reciprocal rank, exact symbol names first, a reason on every result.
- **Call graph:** links with a confidence (`exact`, `import`, `name-match`), used to add the neighbors of top results as signatures.
- **Packing:** answers fitted into a token budget, grouped by file in line order, never over the budget.
- **Project memory:** decisions, conventions, gotchas, and todos linked to code, mirrored to `.remimem/memory.json`, marked stale when the code changes.
- **MCP server:** nine tools and the `remimem://overview` resource, with changed files re-indexed before each call.
- **CLI:** `init`, `index`, `watch`, `serve`, `search`, `context`, `memory`, `stats`, `doctor`, and `bench`.
- **Benchmark:** three open-source repositories, a grep-and-read baseline, ablations, and a held-out test split.

The project was developed under the working name codemem and renamed before release, because that name was taken on npm.
